# Dataframe Optimization (Polars & Pandas)

Notebook focused on practical dataframe performance:
- Titanic analysis using Polars (typed schema + groupby/filter)
- Faster statistics in Pandas using Bottleneck
- Pandas memory optimization (dtype downcasting + boolean/category conversion)

## Datasets
- `train.csv` (Titanic)
- `Housing.csv`

## Tech Stack
- Python
- Jupyter Notebook
- Polars + PyArrow
- Pandas + NumPy
- Bottleneck

## Run
1. Place datasets in `data/`:
   - `data/train.csv`
   - `data/Housing.csv`
2. Open the notebook and run all cells.
